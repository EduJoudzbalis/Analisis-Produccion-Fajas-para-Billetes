# Analisis-Produccion-Fajas-para-Billetes
Análisis de producción de fajas bancarias (Máquina Laurenti) usando SQL y Python. Se digitalizaron bitácoras manuales para detectar patrones de falla. Hallazgo clave: Pérdida del 24% de eficiencia por problemas en sensores y contactores. Propuesta de mantenimiento preventivo basada en datos.
